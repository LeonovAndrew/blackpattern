# План доработки сайта Black Pattern

## Цель

Довести главную страницу, журнал, формы, визуальную систему и SEO до требований ТЗ. Все повторяемые сущности должны управляться через инфоблоки, глобальные данные — через модуль настроек, редко изменяемый текст — через включаемые области.

## Принцип хранения контента

| Контент | Где хранить |
|---|---|
| Логотип, бренд, телефон, email, ссылки, юридические данные | Модуль `blackpattern.settings` |
| Hero: тексты, кнопки, видео, poster, показатели | Инфоблок типа «Главная», инфоблок «Hero» |
| Модули Marketing OS и цены | Существующие инфоблоки типа «Главная» |
| Сотрудники, FAQ, журнал | Существующие инфоблоки типа «Контент» |
| Поля и результаты форм | Инфоблоки типа «Формы» |
| Редко изменяемые тексты и пояснения | Включаемые области |
| Интерактивная разметка, калькулятор, графики и логика | Шаблон и JS, без редактирования из админки |

## Определение готовности
